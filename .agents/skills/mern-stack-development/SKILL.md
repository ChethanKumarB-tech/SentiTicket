# SentiTicket MERN Development Skill

## Project
SentiTicket is a smart support ticketing system that provides SLA breach prediction, RBAC, ticket lifecycle, and audit monitoring.

## Technology Stack
- Frontend: React, Vite, CSS design tokens, Motion UI
- Backend: Node.js, Express.js, REST API, Mongoose, MongoDB Atlas
- Prediction: Python, FastAPI, scikit-learn
