# SentiTicket DevOps & Infrastructure Security Skill

## Objective

Deploy and operate SentiTicket securely across development, testing, staging and production environments.

Security must cover:

- Application deployment
- Docker
- CI/CD
- Networking
- Servers
- MongoDB
- ML service
- Secrets
- HTTPS
- Monitoring
- Backups
- Disaster recovery

Never expose internal infrastructure unnecessarily.
