# SentiTicket Frontend UI/UX Skill

## Objective
Build a professional, modern, secure, responsive, accessible and implementation-ready frontend for SentiTicket.
SentiTicket is a smart support ticketing system with SLA breach prediction and proactive monitoring.

The frontend must prioritize operational clarity:
1. Critical tickets
2. At-risk tickets
3. SLA remaining time
4. SLA risk
5. Prediction risk
6. Required action
7. Ticket priority
8. Agent workload
