# SentiTicket File Upload Security Skill

## Objective

Secure all ticket attachments and file operations.

Files must be treated as untrusted input.

The system must protect against:

- Malicious files
- Executable uploads
- Path traversal
- MIME spoofing
- Oversized files
- Unauthorized downloads
- Cross-organization access
- Malware
- Storage abuse
- Sensitive file exposure
