# SentiTicket Dependency & Supply-Chain Security Skill

## Objective

Keep all third-party software used by SentiTicket secure, maintained, auditable and reproducible.

This applies to:

- Node.js
- npm
- React
- Express
- Mongoose
- Python
- FastAPI
- ML libraries
- Docker images
- GitHub Actions
- Development tools
- Testing tools
- Build tools

Never add a dependency simply because it is convenient.
